# How to Get Your Android APK — Step by Step

This project uses **GitHub Actions** to build the APK in the cloud.
No Java, no Android Studio, no local setup needed on your machine.

---

## Prerequisites

- A free **GitHub account**: https://github.com
- Your project files pushed to a GitHub repository

---

## Step 1 — Push this project to GitHub

If you haven't already:

1. Go to https://github.com/new and create a **new repository**
   - Name it: `velvetledger-pos` (or anything you like)
   - Set it to **Private** (recommended — your business data)
   - Do **not** initialize with README

2. Open a terminal in your project folder and run:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

> Replace `YOUR_USERNAME` and `YOUR_REPO_NAME` with your actual GitHub username and repo name.

---

## Step 2 — Trigger the APK build

The build starts **automatically** when you push to `main`.

Or trigger it manually:

1. Go to your repository on GitHub
2. Click the **Actions** tab
3. Click **"Build Android APK"** in the left sidebar
4. Click the **"Run workflow"** button (top right)
5. Click the green **"Run workflow"** confirmation button

---

## Step 3 — Wait for the build (~10–15 minutes)

You'll see a running workflow. It:
- Installs Node.js and builds the web app
- Sets up Java 17 + Android SDK 34
- Compiles the app with Gradle
- Produces a signed debug APK

A green ✓ means success. A red ✗ means something failed — click it to see logs.

---

## Step 4 — Download the APK

1. Click the completed workflow run
2. Scroll down to the **Artifacts** section
3. Click **"UsmanClothPOS-APK"** — it downloads as a `.zip`
4. Extract the zip → you get **`UsmanClothPOS-v2.0.0-debug.apk`**

---

## Step 5 — Install on your Android phone

1. **Transfer** the APK to your phone (WhatsApp, cable, Google Drive, etc.)
2. On your phone, go to **Settings → Security → Install unknown apps**
   - Enable it for your file manager or browser
3. Open the APK file and tap **Install**
4. Once installed, the **Usman Cloth POS** icon appears on your home screen

## Troubleshooting

**Build fails at Gradle step:**
- Check the Actions log for the exact error
- Most common cause: Android SDK version mismatch — the workflow handles this automatically

**"App not installed" on phone:**
- Make sure you enabled "Install from unknown sources"
- Delete any previous version of the app first, then install

**APK downloads as a .zip:**
- That's normal — GitHub wraps artifacts in a zip. Extract it to get the `.apk`

**Want a release APK (smaller, optimized)?**
- Go to Actions → Run workflow → choose `release` from the dropdown
- A release APK requires a signing keystore (contact for setup instructions)

## What's Inside the APK

This is a **Capacitor WebView APK** — it bundles the entire web app
(`dist/` folder) inside a native Android shell. The app:

- Works fully **offline** (all data stored in the phone's localStorage)
- Supports **Bluetooth thermal printing** (Web Bluetooth API)
- Sends **WhatsApp & SMS reminders** via Android intents
- Has a **PIN login screen** for operator security
- Looks and behaves exactly like the web app, but runs as a native Android app
